# SecSig

Настольное приложение на **Python 3** для интерактивного просмотра многоканальных временных рядов (форматы **CSV**, **Excel**, **Parquet**), расчёта характеристик по участкам тензосигнала и виброанализа (в том числе спектр Уэлча, СКЗ в полосах, эквивалентные амплитуды для синусоидальной модели). Интерфейс реализован на **PyQt5**, графики — **pyqtgraph**.

## Требования

- Python 3.10 и выше  
- Зависимости перечислены в `pyproject.toml` и файле `requirements.txt`

## Установка

```bash
pip install -r requirements.txt
```

Для разработки и запуска тестов дополнительно:

```bash
pip install -r requirements-dev.txt
```

## Запуск

```bash
python -m app.app
```

## Тесты

```bash
pytest tests/ -v
```

## Структура проекта

```
app/
  app.py              # точка входа
  ui/                 # главное окно, графики, панели, диалоги
  io/                 # загрузка рядов, сохранение проекта (.secsig)
  processing/         # алгоритмы тензометрии и виброметрии
  core/models/        # модели рядов и наборов данных
tests/                # автоматические тесты (pytest)
```

## Файлы проекта

Состояние рабочей сессии хранится в **JSON** с расширением `.secsig`: пути к исходным файлам, какие ряды выведены на графики, геометрия «стиков» и масштаб по оси времени. Числовые данные при открытии проекта снова читаются из исходных файлов.
